Two different physical problems

The internet was built to distribute information between humans. Inference infrastructure must produce intelligence between machines.

The internet

Moves what we already know

  • Web pages, files, email, search and video
  • Store it somewhere, request it, send it
  • Rewards reach, redundancy and scale
  • Tolerates distance as the price of all three
vs

Inference

Produces what we don't know yet

  • Tokens generated one after another from huge model state
  • Every token depends on the ones before it
  • Rewards memory locality, bandwidth and thermal control
  • Punished by distance at every hop

Every hop is a tax

Agentic AI turns one user action into hundreds of model calls, tool calls and checks. Latency doesn't just slow the answer. It compounds through the whole chain.

A 50 ms penalty, repeated across a chain of machine-speed calls, becomes a real economic cost.

The industry is already rebuilding around locality

None of today's inference tricks exist to move state faster across distance. Every one of them exists to avoid moving it.

FlashAttentionFewer reads and writes to memory
Kernel fusionAvoids round trips between memory and compute
QuantizationShrinks how many bits have to move
Prefix cachingReuses state instead of recomputing it
Cache-aware routingSends the request to where the state already lives
DisaggregationSplits prefill and decode onto the hardware each needs

"The winning systems are not the biggest clusters. The systems that place memory, compute, routing, and power closest to the demand pattern will win."
