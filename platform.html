Two different physical problems.

The internet was built to distribute information between humans. Inference infrastructure must produce intelligence between machines.

The internet

Built for
Asynchronous human-scale workloads: web pages, files, email, search queries, streaming video
Main work
Store information, request it, transmit it, consume it with tolerable latency
Rewards
Reach, redundancy, and scale
Distance
Tolerated as the price of all three
vs

Inference

Built for
Continuous machine cognition: tokens generated from enormous state
Main work
Repeated transformations of model weights, activations, attention maps, and KV cache
Rewards
Memory locality, bandwidth density, low-latency interconnect, and thermal control
Distance
Punished at every hop

The industry is already rebuilding around locality.

None of the inference toolkits exist to move state faster across distance. Every one of them exists to avoid moving it. Together they are an industry rebuilding around locality.

FlashAttention
Reduces unnecessary reads and writes to memory.
Kernel fusion
Avoids round trips between memory and compute.
Quantization
Shrinks the number of bits that have to move at all.
Prefix caching
Reuses prior KV state instead of recomputing it.
Cache-aware routing
Sends the next request to wherever the relevant state already lives.
Disaggregation
Splits prefill and decode because they punish different parts of the machine.

Every hop is a tax.

An agentic application can trigger chains of model calls, tool calls, retrieval steps, code execution and verification passes. One user action can become hundreds or thousands of inference events. Latency does not merely affect user experience. It compounds through the reasoning graph.

A 50 ms penalty repeated across a long chain of machine-speed operations becomes a real economic tax.
