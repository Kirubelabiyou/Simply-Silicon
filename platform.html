How each city site is built.

We turn latent utility infrastructure and own-use power into bare metal inference compute, faster than conventional developers. Every site follows the same four steps.

1

Find latent power

A utility site inside the city that already has large power connections and space to spare.

2

Convert in phases

Install bare metal GPU servers inside the existing building, starting small and growing phase by phase.

3

Run private fiber

Lay private fiber from the site to the buildings nearby, kept apart from the public internet.

4

Join the network

Link the new site to the others, adding one more node to the private network.
